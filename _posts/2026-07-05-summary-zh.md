## [仅用 445 字节数据生成世界地图](https://simonwillison.net/2026/Jul/4/building-a-world-map-with-only-500-bytes/#atom-everything) ⭐️ 7.0/10

Iwo Kadziela 展示了一种方法，仅用 445 字节数据，通过 deflate 压缩和 JavaScript fetch 管道结合 data URI，生成了一个可辨认的 ASCII 世界地图。 该方法展示了如何将压缩算法与现代 Web API 相结合，以极少量数据实现复杂可视化，这对于资源受限的环境或代码高尔夫等技术挑战具有启发意义。 地图数据采用 deflate-raw 压缩并嵌入为 base64 编码的 data URI，在浏览器中通过 Compression Streams 规范的 DecompressionStream API 解压缩。

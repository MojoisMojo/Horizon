## [LinkedIn 招聘陷阱传播 npm 后门](https://roman.pt/posts/linkedin-backdoor/) ⭐️ 8.0/10

一名冒充加密货币初创公司招聘人员的虚假 LinkedIn 招聘者向开发者发送恶意 GitHub 仓库，利用 npm 在 `npm install` 后自动执行 `prepare` 脚本的特性植入后门。 这次攻击展示了结合社交工程的现实威胁和软件供应链漏洞，凸显开发者在求职过程中极易被攻破，以及改善网络犯罪举报基础设施的紧迫性。 后门隐藏在注释掉的测试代码中，允许服务器执行任意命令。npm 的默认行为会在安装依赖时自动执行 `prepare` 脚本，使攻击无需用户额外操作。

hackernews · lwhsiao · 6月15日 20:00 · [社区讨论](https://news.ycombinator.com/item?id=48546294)

**背景**: npm 是 Node.js 的包管理器，允许在 `package.json` 中定义生命周期脚本。`prepare` 脚本用于构建或设置包，但在旧版 npm 中会在 `npm install` 后自动运行而不提示。供应链攻击利用对软件依赖的信任，社会工程则诱骗用户安装恶意代码。SolarWinds 等事件已表明此类威胁的严重性。

## [Iroh 1.0 发布：支持自定义传输的 P2P 网络库](https://www.iroh.computer/blog/v1) ⭐️ 8.0/10

基于 Rust 的点对点网络库 Iroh 1.0 正式发布，允许应用通过拨号密钥和中继进行连接，并新增了自定义传输的实现能力。 此次发布使开发者能够嵌入直接、安全的点对点连接，无需用户管理 VPN 或额外账户，大大降低了构建去中心化应用的门槛。 Iroh 使用加密的“拨号密钥”（可能基于公钥）建立连接，原生支持 IPv4、IPv6 和中继传输，并提供了自定义传输的接口，可集成 WebRTC、BLE 等其他协议。

Hacker News 上的开发者分享了用本地模型替代云端编程助手（如 Claude 和 GPT）的成功经验，他们使用的模型主要是 Qwen3.6 35b 和 27b，搭配 Pi harness、OpenCode 和 Llama.cpp 等工具，在 Mac Studio 128GB、双 RTX 3090 等硬件上运行，生成速度可达 150 tokens/秒。 这一转变表明本地开源模型在专业编程中已具备可行性，能提供数据隐私、节省成本和摆脱供应商 API 的优势。这动摇了云端前沿模型的必要性，并可能使强大的 AI 编程工具更加普及。 用户指出，Qwen3.6 等模型通过减少激活参数（如 35B 中仅 3B 活跃）实现高速运行，但能力略弱于云端模型，大约相当于 8-12 个月前的边缘模型。部分开发者在复杂任务上仍会回退到 Claude 或 Copilot，并且此类方案需要 24GB 以上显存的 GPU 等高端硬件。

hackernews · cloudking · 6月15日 14:46

**背景**: Qwen 是阿里巴巴云开发的一系列大语言模型，许多变体以开源许可证发布。本地 LLM 在用户自有硬件上运行，通常采用量化（如 GGUF 格式）和混合专家等技术降低资源消耗。Llama.cpp 和 OpenCode 等工具为这些模型提供了高效的编程辅助接口。

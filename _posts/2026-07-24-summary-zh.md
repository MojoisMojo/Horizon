## [ChannelGuard：安全的 LLM 组合成不安全的多智能体系统](https://arxiv.org/abs/2607.19430) ⭐️ 8.0/10

研究人员发现，单独安全的 LLM 组合成多智能体系统后会变得不安全，因为智能体之间未受监控的通道会走私恶意指令。他们提出了 ChannelGuard，一种无需训练的防御框架，在每个通道上设置信息瓶颈门，完全阻止工具投毒攻击，并将提示注入攻击成功率降低一半。 这项研究揭示了多智能体 LLM 安全的一个关键盲点：仅关注输入端的标准防御无法监控智能体间的通信，导致攻击能够绕过原本安全的模型。ChannelGuard 提供了一种跨后端实用且无需训练的防御方案，凸显了保护整个多智能体流水线的必要性。 关键发现：未防御流水线在工具投毒上的安全性几乎完全归功于 Azure GPT-5 的服务器端过滤器；ChannelGuard 的工具输出门在 Azure、Anthropic Sonnet 4.5 和 Haiku 4.5 上均实现 30/30 的阻止率。局限性：嵌入相似度门可能被自适应改写绕过，此时扰动投票基线方法更稳健。

rss · arXiv Multi-Agent Systems · 7月24日 04:00

**背景**: 多智能体 LLM 系统将规划器、工作智能体、验证器等链接起来解决复杂任务。智能体之间通过未监控的文本通道通信，可能被利用来走私恶意指令。现有安全措施（如输入防护栏或服务器端过滤器）仅检查初始输入或最终输出，导致智能体间通道脆弱。该论文表明，即使每个模型单独安全，组合后仍可能不安全。

## [MKEvolve：模块化多智能体内核生成框架](https://arxiv.org/abs/2607.20501) ⭐️ 8.0/10

MKEvolve 是一个模块化多智能体框架，它迭代地共同演化 PyTorch 模块分解和 LLM 生成的内核，提高硬件加速器上的正确性和性能。在 Triton 上的 KernelBench L2 和 L3 测试中，它在提升速度的同时将 LLM 令牌使用量减少了高达 35%。 为硬件加速器编写正确且高效的内核是扩展机器学习工作负载的关键瓶颈。MKEvolve 的模块化方法使内核可配置、可解释且易于适配，可能加速 AI/ML 系统的开发。 该框架通过分裂和融合迭代优化子模块，并利用 LLM 驱动的束搜索独立改进每个子内核。子内核可组合和替换，错误和加速可追溯到具体组件。实验覆盖 KernelBench 上的多算子序列（L2）和完整模型架构（L3）。

rss · arXiv Multi-Agent Systems · 7月24日 04:00

**背景**: Triton 是 OpenAI 开发的开源 GPU 编程语言，让研究人员无需 CUDA 经验即可编写高效内核。KernelBench 是一个基准测试，评估 LLM 为 250 个 PyTorch 工作负载生成高效 GPU 内核的能力。基于 LLM 的内核生成因严格的正确性和性能要求而具有挑战性。

## [蒙特卡洛 dropout 不确定性标志减少胸部 X 光 AI 误诊](https://arxiv.org/abs/2607.20582) ⭐️ 8.0/10

将蒙特卡洛 dropout 应用于多任务胸部 X 光分类器，得到的认知不确定性信号将误差检测 AUROC 从 0.74 提升至 0.77，并在临床决策支持实验中以二进制风险标志呈现时，将自信误诊率从 8.5%降至 2.7%。 这表明以简单的二进制标志而非原始分数传达不确定性，可以显著改善医疗 AI 的诊断安全性，直接提升临床医生信任度和患者预后。 误差检测 AUROC 的提升（+0.023）虽不大但统计显著；关键在于使用二进制标志时自信误诊率下降 6.8 个百分点，凸显了不确定性沟通方式的影响。

rss · arXiv Multi-Agent Systems · 7月24日 04:00

**背景**: 蒙特卡洛 dropout 在推理时保持 dropout 激活并执行多次随机前向传播，以近似预测分布，提供认知（模型）不确定性。AUROC 衡量分类器的区分能力。胸部 X 光片是用于诊断胸部疾病的 X 射线影像。

## [提出 Mode 0：基于路侧计算单元的新型 3GPP V2X 资源分配类别](https://arxiv.org/abs/2605.25431) ⭐️ 8.0/10

研究人员提出 Mode 0，一个利用路侧计算单元（RCU）的新 3GPP V2X 资源分配类别，RCU 集成了感知、直连通信和本地计算功能。仿真结果显示 Mode 0c 的分组投递率（PDR）达到 0.999，并将最差时间间隔 PDR 从接近零提升至 0.601，满足第 95 百分位时延要求。 该提案填补了蜂窝 V2X 标准的结构性空白，通过基础设施协调的资源分配，在密集交通和危险场景下提升了安全性。它有可能成为新的 3GPP 研究项目，从而影响未来全球互联车辆的部署。 Mode 0 包含从 Mode 0a（全被动 UE）到 Mode 0c（全主动 UE）的子类谱系。通过多智能体近端策略优化（MAPPO）仿真，Mode 0c 对两类 UE 均有严格帕累托改进，并且是唯一在结构上满足第 95 百分位时延要求的配置。

rss · arXiv Multi-Agent Systems · 7月24日 04:00

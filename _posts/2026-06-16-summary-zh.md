## [多智能体系统的优势幻觉](https://arxiv.org/abs/2606.13003) ⭐️ 9.0/10

一项系统性评估发现，自动生成的多智能体系统在多种推理和交互任务中始终不如单智能体的思维链自一致性（CoT-SC）方法，且运行成本高达 10 倍以上。 这一发现质疑了多智能体系统更优的普遍观念，可能通过揭示复杂架构的低效性和严格成本效益分析的必要性，重塑 AI 系统设计范式。 研究引入了一个专为 MAS 设计的诊断合成数据集，发现专家设计的架构在性能和成本效率上均优于自动生成的系统；后者存在“架构膨胀”，表层复杂却未带来实际功用。

rss · arXiv Multi-Agent Systems · 6月16日 04:00

**背景**: 多智能体系统（MAS）由多个 AI 智能体协同工作，单智能体系统则使用单一模型。思维链（CoT）提示通过展示逐步推理过程提升表现，自一致性（SC）则通过采样多条推理路径及答案投票增强可靠性。以往对 MAS 优势的验证多基于孤立的推理测试，未充分评估其在交互式多步任务中的表现。

## [关于浏览器会话 JWT 安全性的辩论升温](https://gist.github.com/samsch/0d1f3d3b4745d778f78b230cf6061452) ⭐️ 8.0/10

一篇名为“停止使用 JWT”的批评性文章引发了关于在浏览器会话中使用 JSON Web 令牌的安全漏洞的细致讨论，许多评论者限定了范围并辩论替代方案。 这场辩论凸显了 Web 开发者在选择认证机制时的关键安全权衡，可能影响数百万应用如何处理用户会话和保护敏感数据。 核心问题在于 JWT 是无状态的，如果没有撤销列表或短有效期等额外基础设施，就很难被撤销，并且如果签名或存储不当可能会暴露漏洞。

**背景**: JSON Web 令牌（JWT）是一种紧凑、自包含的声明传输方法，常用于无状态认证。在浏览器应用中，它们通常存储在客户端，与传统的服务器端会话不同。辩论的焦点在于 JWT 的便利性是否超过其安全挑战。

## [杀戮尖塔 2 定制 PRNG 确保跨平台种子一致性](https://tck.mn/blog/correlated-randomness-sts2/) ⭐️ 8.0/10

杀戮尖塔 2 采用自定义伪随机数生成器，以避免使用 Godot 引擎中 C# System.Random 时出现的相关随机性问题，并确保在不同平台间种子的一致性。 这确保了公平且可复现的游戏体验，使玩家能跨平台共享种子，并防止因标准库变更导致种子失效，同时为游戏开发中使用自定义 PRNG 提供了先例。 该自定义 PRNG 使用 32 位哈希函数处理种子，因此实际可用种子数为 40 亿（初代为 64 位），这简化了无法获胜种子的暴力破解分析，但减少了高随机种子的多样性。

hackernews · rdmuser · 6月16日 09:46 · [社区讨论](https://news.ycombinator.com/item?id=48552844)

**背景**: 伪随机数生成器（PRNG）是从初始种子生成近似随机数序列的算法。在游戏中，PRNG 控制程序化生成、战利品掉落和敌人行为。使用标准库的 PRNG 可能因平台实现差异导致不同序列。内嵌于游戏代码的自定义 PRNG 可确保所有平台行为一致，这对于杀戮尖塔这类流行 Roguelike 卡牌游戏中的种子共享至关重要。
